# Dashboard Fuerza de Ventas - Almacenes MexCom

## Descripción
Dashboard interactivo para análisis de desempeño de ventas en almacenes de cadena con múltiples sucursales en México.

## Métricas Principales
- Total facturado: $21.0M MXN
- Mayor venta: $1.8M MXN
- Menor venta: $1.6M MXN
- Volumen de compras: 89,823 transacciones
- Promedio de venta: $1.7M MXN

## Métodos de Pago
- Efectivo: 39%
- Electrónico: 36%
- Otros (vales de despensa): 25%

## Contenido
- 89,823 registros de transacciones ficticias (12 meses)
- Slicers dinámicos por cajero y día
- Macro VBA que cambia foto del cajero automáticamente

## Cómo Usar
1. Abre en Excel (2016 o superior)
2. Archivo y carpeta "Fotos dashboard" en la misma carpeta
3. Habilita macros
4. Usa slicers para filtrar
5. Gráficas se actualizan automáticamente

## Datos
Datos ficticios para operación realista de almacén México. Tipo de cambio: 17.90 MXN/USD.

## Nota Legal
Modelo educativo y portfolio. Datos, nombres y transacciones ficticios.
